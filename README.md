# 깃든마켓

오픈소프트웨어플랫폼 Team Project Practice 2 제출본입니다. 저장소를 내려받아 `product_list.html`을 브라우저에서 열면 화면을 확인할 수 있습니다.

| 화면 | 미리보기 파일 |
| --- | --- |
| 상품 목록 | [product_list.html](product_list.html) |
| 상품 등록 | [templates/product_register.html](templates/product_register.html) |
| 상품 상세 | [templates/product_detail.html](templates/product_detail.html) |
| 등록 결과 | [templates/product_result.html](templates/product_result.html) |
| 리뷰 목록 | [review_list.html](review_list.html) |
| 리뷰 작성 | [review_write.html](review_write.html) |
| 리뷰 상세 | [review_detail.html](review_detail.html) |
| 회원가입 | [signup.html](signup.html) |
| 로그인 | [templates/login.html](templates/login.html) |
| 커미션 요청 | [commission_request.html](commission_request.html) |
| 룰렛 | [templates/roulette.html](templates/roulette.html) |

상품 카드를 누르면 해당 작품의 상세를 볼 수 있습니다. 상품 상세의 **리뷰** 탭에서 리뷰 목록을 보거나 바로 리뷰를 작성할 수 있고, **커미션 신청하기**로 해당 작품의 요청 화면을 엽니다.

커미션 완료와 룰렛 당첨·꽝 결과는 브라우저에서 시연합니다. 상품 등록 결과는 예시 데이터이며 로그인, 리뷰·커미션의 서버 저장, 보상 지급, 등록 화면의 지도 핀 선택은 기능 구현 단계에서 연결합니다.
